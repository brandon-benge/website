Getting started

  1. 1
    Install AI CAD
    Available on Mac and iPhone/iPad once published to the App Store.
  2. 2
    Connect your repository
    AI CAD currently connects via the AI CAD GitHub App, so your project's source, history, and generated files live in a repository you control — not on a server we run. Support for other ways to host your own project is part of the bigger roadmap.
  3. 3
    Start a project
    Create a new project from a template, or import one you already have.
  4. 4
    Ask for what you want
    Describe the change in plain language. AI CAD uses your choice of AI provider to propose Python source changes, then validates and builds them before you see a preview.
  5. 5
    Review, preview, and push
    Nothing is accepted automatically. Review the build, then commit and push to your repository whenever you're ready.

Bring your own infrastructure

AI CAD doesn't run its own AI backend, and it doesn't hold your project hostage on a server we run. You connect the AI provider you already trust — OpenAI, Anthropic, Google, OpenRouter, Groq, xAI, DeepInfra, Mistral, or OpenCode — using your own API key, stored only on your device, while your project itself lives in a repository you control. See the Privacy Policy for exactly what that means for your data.
