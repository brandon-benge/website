Where MakeItOurs is headed

Today's MakeItOurs is small, sharp, and GitHub-powered. Here's the bigger idea we'd love to build next — if it gets funded.

Heads up

Everything below the "Today" section is a direction, not a promise. It describes what we'd build with real funding and engineering time behind it — not a shipping date. If you'd like to help make it real, say hello on the Support page.

Today
MakeItOurs, powered by your GitHub

Right now, MakeItOurs is deliberately simple: your project lives in a GitHub repository you own. You describe a change, MakeItOurs proposes and validates Python source, builds a preview, and you decide what gets pushed. No hidden server holds your design — GitHub does, because you already trust it.

V2
MakeItOurs V2 — the bigger idea

🏡 A home for MakeItOurs that isn't borrowed

GitHub is great, but it wasn't built to be a CAD platform. V2 imagines MakeItOurs owning its own place for your projects, history, previews, and AI-assisted builds — with GitHub becoming an optional door in, not a requirement to get started. A subscription tier could also take the operational overhead off your plate entirely — no GitHub Actions budget to watch, no infrastructure to monitor. Bringing your own GitHub and AI provider would stay available for anyone who wants full control; it just wouldn't be the only path anymore.

🎯 Download exactly what you need, nothing you don't

Big projects have lots of moving parts — wiring, framing, structure, finishes. V2's preview would let you check or uncheck exactly the pieces you care about, and generate only those files, on demand. Need just the wiring diagram? That's all you'd have to wait for.

🌱 Branch your ideas, not just your code

One good idea often turns into three good options. V2 would let you fork a project into named alternatives, explore each one independently, and always see how they relate back to the original — without juggling duplicate projects or losing track of where an idea came from.

✏️ Sketch it, and let AI take a first pass

Sometimes "make the frame two inches wider here" is easier to draw than to type. V2's vision is to let you sketch or mark up a view directly, have AI interpret your intent, and come back with a clear, reviewable proposal for the underlying Python change — never a silent edit. You'd always see exactly what changed and why before accepting it.

🖐️ Direct, hands-on editing — done carefully, not rushed

Drag-and-drop editing is tempting, but it's easy to get wrong for a tool where the underlying design math has to stay correct. Before we build anything like that, V2 commits to researching the options properly — what preserves the real parametric design intent, what's just a nice-looking illusion, and what's actually safe to ship.

V3
MakeItOurs V3 — build from a photo

Sometimes the easiest starting point isn't a description — it's the object itself. V3 imagines pointing your phone at something in the real world and having MakeItOurs break it down into a parametric project: recognizing its shapes, proportions, and materials, then rebuilding it as an editable Python CAD model you can refine, build, and export just like a project you started from scratch.

V4
MakeItOurs V4 — price the path from before to after

Once you can compare where a project is today against where you want it to be, the next question is what that change actually costs. V4 imagines comparing a "before" and "after" version of a project to work out exactly which materials are needed to get from one to the other, pricing that materials list, and pulling contractor estimates for the build itself based on your location — turning a design change into a real budget, not just a preview.

Want this to happen sooner?

V2, V3, and V4 are a funding-dependent roadmap, not a backlog with a date on it. If you're interested in supporting it — as a customer, an investor, or a collaborator — reach out from the Support page.
